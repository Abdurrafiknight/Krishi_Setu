# Krishi Setu – Agricultural Market Management System

Krishi Setu is an **Agricultural Market Management System** designed to connect farmers and buyers through a digital agricultural marketplace. The system provides separate interfaces for **Farmers, Buyers, and Super Admins** to manage agricultural products, orders, transactions, promotional discounts, and commission records.

## Project Overview

The main goal of Krishi Setu is to provide a simple and organized platform where farmers can list their agricultural products and buyers can browse and purchase those products.

The system also allows the Super Admin to manage users, product listings, promotional codes, commission rates, and overall system activities.

## Main Actors

### Farmer

* Register and log in to the system
* Manage profile and bank account information
* Add, edit, and remove product listings
* View incoming order requests
* Accept or reject buyer orders
* Track sales, payments, and earnings
* Track order and delivery status

### Buyer

* Register and log in to the system
* Manage profile and delivery address
* Browse and search agricultural products
* View product details
* Add products to cart
* Apply promotional codes
* Place orders and make payments
* Track order and delivery status

### Super Admin

* Log in to the admin panel
* Approve or suspend farmer and buyer accounts
* Manage product listings
* Create, update, and deactivate promo codes
* Configure transaction commission rates
* View commission and revenue information
* Monitor overall system activities

## Key Features

* User registration and login
* Farmer product management
* Buyer product browsing and purchasing
* Shopping cart and order management
* Promotional discount codes
* Transaction management
* Commission management
* Order and delivery status tracking
* Admin dashboard and management
* SQL Server database integration

## Database

The project uses **SQL Server** as the database management system.

The main database entities are:

* Farmer
* Buyer
* Admin
* Product
* Promo Code
* Transaction
* Commission

The database is designed using normalization principles and uses primary and foreign key relationships to maintain data integrity.
